# Curso Web Basico

Este projeto e uma landing page simples feita para uma atividade de HTML, CSS e JavaScript.

## Sobre o projeto

A pagina apresenta um curso ficticio de desenvolvimento web basico. Ela possui:

- Cabecalho com menu de navegacao.
- Texto principal com botao de inscricao.
- Secao sobre o curso.
- Consulta de endereco usando a API ViaCEP.
- Formulario de contato.

## Tecnologias usadas

- HTML
- CSS
- JavaScript
- API ViaCEP

# Estrutura do projeto

```
├── index.html
├── script.js
├── styles.css
└── README.md
```

## Como usar

Abra o arquivo `index.html` no navegador.

No campo de CEP, digite um CEP valido e clique em `Buscar` para consultar o endereco.

## Estrutura dos arquivos

- `index.html`: estrutura da pagina.
- `styles.css`: estilos e cores da pagina.
- `script.js`: interacoes, formulario e consulta ViaCEP.
